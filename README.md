# TVBox Video Sources · 4K 影视源

适用于 **TVBox / 影视仓 / OK影视** 等兼容壳子的 **TVBox 配置索引页**，按分区整理影视源、直播源。

所有源**地位相同**，没有「主线路 / 备用线路」之分，任选一条即可。

- 页面：<https://soys1.github.io/TVBox-Video-Sources/>
- 源列表：[`4K视频源.md`](./4K视频源.md)

---

## 使用流程

> **需要登录网盘**，普通账号即可，**不需要网盘会员**。
> 视频报错时看报错内容对症处理，多数是没登录 / 登录失效 / 资源失效。

1. 点「**复制地址**」
2. 打开支持 TVBox 影视源的软件，**添加地址链接**
3. 保存后，进入「**配置中心**」这类分区，**登录网盘**即可

各源的登录方式不完全相同，以所用源里「配置中心」的提示为准。

## 页面功能

- **卡片网格**：一条源一张卡片，桌面端 2 列、手机端 1 列，卡片带该源的 logo
- **分区展示**：影视源、直播源各占一块，互不干扰
- **复制地址**：一键复制配置链接，直接填进 TVBox
- **二维码**：扫码导入，适合电视端
- **查看包含的源**：列出这条配置里收录的站点（站名 / key / 类型），可搜索
  - 只支持允许浏览器跨域读取的源；看不了**不影响使用**，复制地址照常能用

## 怎么更新源

**分区分文件管理**，每个分区一个 md，改哪个推哪个：

| 分区 | 文件 |
| --- | --- |
| 🎬 4K 影视源 | [`4K视频源.md`](./4K视频源.md) |
| 📺 直播源 | [`直播源.md`](./直播源.md) |

一行一个地址，推送到 `main` 后页面自动更新：

```md
https://9280.kstore.vip/aiwex.json
```

| 写法 | 效果 |
| --- | --- |
| `https://a.com/x.json` | 一条源（不写名称时卡片只显示这条链接） |
| `名称 \| https://b.com/y.json` | 给这条源加显示名称 |
| `名称 \| https://b.com/y.json \| https://b.com/logo.png` | 再指定卡片上的 logo |
| `https://b.com/y.json \| https://b.com/logo.gif` | 不写名称，只加 logo |
| `- https://c.com/z.json` | markdown 列表写法也支持 |
| 空行、`#` / `//` 开头的行、```` ``` ```` 围栏 | 自动忽略（可写注释） |

某个分区文件里没有有效地址时，该分区自动隐藏，不会出现空白区。

### 加一个新分区

在 `index.html` 顶部的 `CATEGORIES` 里照着加一条，再建一个同名 md 文件即可：

```js
{
  id: 'music',                 // 唯一标识
  title: '音乐源',              // 分区标题
  icon: '🎵',                   // 分区图标
  desc: '一句话说明',            // 标题旁灰字
  file: '音乐源.md',            // 数据文件
  note: '填写说明（可选）'        // 分区顶部小字
}
```

### 卡片 logo

卡片左上角那个小图标，取图顺序是：

1. `4K视频源.md` 里手写的 logo（第三个字段）
2. 没有就自动读该源配置 JSON 里的 `"logo"` 字段
3. 都拿不到就用一个播放器占位图标

所以换 logo **只需要改 md 文件**，不用动页面；配置里自带 logo 的源，页面会自己抓过来显示。
图片加载失败也会自动退回占位图标。

## 部署

推送到 `main` 即自动发布（工作流已配好）。首次需在 **Settings → Pages → Source** 选择 `GitHub Actions`。

- 仓库必须 **Public**，私有仓库的 Pages 对外打不开，TVBox 也拿不到
- Pages 有 CDN 缓存，改完 `4K视频源.md` 最长约 10 分钟生效，急用可加 `?v=2` 强制刷新
- 页面没更新时，去 **Actions** 里对失败的 run 点 **Re-run failed jobs**

## 本地预览

`fetch` 读本地文件需要 http 环境，直接双击 `index.html` 会走内置兜底列表：

```bash
python -m http.server 8000
```

然后打开 <http://localhost:8000/>。
