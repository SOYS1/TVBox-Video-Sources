# TVBox Video Sources · 4K 影视源

一个单文件（`index.html`）的 **TVBox / 影视仓 / OK影视 配置发布页**：把 4K 源渲染成**卡片网格**，每张卡片都能一键复制地址、扫码导入。

所有源**地位相同**，没有「主线路 / 备用线路」的概念，任选一条即可。

> 页面内容不需要维护 —— 它会在加载时**自动读取同目录下的 [`4K视频源.md`](./4K视频源.md)** 并渲染。

- 仓库：<https://github.com/SOYS1/TVBox-Video-Sources>
- 页面（开启 Pages 后）：<https://soys1.github.io/TVBox-Video-Sources/>

---

## 怎么更新源

直接编辑 `4K视频源.md`，一行一个地址，保存 / 提交即可，页面刷新后自动同步：

```md
https://9280.kstore.vip/aiwex.json
```

规则：

| 写法 | 效果 |
| --- | --- |
| `https://a.com/x.json` | 列表中一条源（序号 01、02…自动生成） |
| `名称 \| https://b.com/y.json` | 该条源带上自定义显示名称 |
| `- https://c.com/z.json` | markdown 列表写法也支持 |
| 空行、`#` / `//` 开头的行、```` ``` ```` 围栏 | 自动忽略（可以写注释） |

每条源都以**卡片**形式展示（封面：域名首字母 + 格式 / 画质标记；主体：名称、域名、地址、操作）：

| 卡片元素 | 说明 |
| --- | --- |
| 序号水印 `01` `02` | 按 md 中的顺序自动生成 |
| `JSON` / `URL` 标记 | 按地址后缀自动判断 |
| 名称 | 有自定义名称时显示名称，否则显示域名 |
| 地址框 | 点一下会全选，方便手抄 |
| 复制地址 / 二维码 | 二维码在弹层中展示，支持 Esc 或点击遮罩关闭 |
| 查看包含的源 | 弹出该配置里的站点列表（可搜索），见下 |

桌面端自适应 2 列、窄屏自动 1 列，所有卡片地位相同，没有主次之分。

### 查看源里包含哪些站点

点卡片底部的「**查看包含的源 ›**」，会弹出这组 TVBox 配置里的站点清单：

- 顶部显示统计：`95 个站点 · 2 个直播 · 4 个解析`
- 每行一个站点：序号、名称、`key`（可搜索的会标「可搜索」）、类型标签（`XML` / `JSON` / `SPIDER` / `EXT`）
- 站点多于 8 个时出现搜索框，可按名称或 key 过滤
- 底部「复制配置地址」可一键复制，方便直接丢给 TVBox

> **注意：** 站点列表是浏览器在访问者本地去拉取该配置 JSON 得到的。
> 配置服务器允许跨域（带了 `Access-Control-Allow-Origin`）时能直接显示，卡片上也会顺手预取显示「95 源」；
> 不允许跨域时会依次尝试几个公共 CORS 代理，仍失败就提示「该源禁止浏览器跨域读取」，并给一个「直接打开配置」的链接。

页面上的「可用源」数量、「已同步 N 条源」状态、「源文件更新」日期都会跟着变。

## 部署（GitHub Pages）

1. 把 `index.html`、`4K视频源.md` 放进仓库**根目录**，推到 `main` 分支。
2. 仓库 → **Settings → Pages** → Source 选 **Deploy from a branch** → Branch `main` / `/ (root)` → Save。
3. 等 1～2 分钟，访问 <https://soys1.github.io/TVBox-Video-Sources/>。

**注意：**
- 仓库必须是 **Public**（私有仓库的 Pages 需要 GitHub Pro 且默认不公开，TVBox 也拿不到）。
- Pages 有 CDN 缓存，改完 md 后最长约 10 分钟生效；急的话用无痕窗口或加 `?v=2` 访问。
- 「源文件更新」日期：在 `github.io` 上会调用 GitHub API 读取该文件的最后一次提交时间，取不到时显示 `—`。

## 本地预览

`fetch` 读本地文件需要 http 环境，**直接双击 index.html 会走内置兜底列表**（页面会提示）：

```bash
# 任选一个
python -m http.server 8000
npx serve .
```

然后打开 <http://localhost:8000/>。
